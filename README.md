# แบบสำรวจพนักงานที่ได้รับผลกระทบจากน้ำท่วม

เว็บสำหรับรวบรวมข้อมูลพนักงานที่ได้รับผลกระทบจากน้ำท่วม มี 2 ส่วน

| หน้า | URL | รายละเอียด |
|---|---|---|
| แบบฟอร์ม | `/` | ให้พนักงานกรอกข้อมูล (ใช้บนมือถือได้) |
| Dashboard | `/dashboard` | สรุปข้อมูลแบบ real-time พร้อมตัวกรองทุกหัวข้อ |

## วิธีรัน

ต้องใช้ Node.js 18 ขึ้นไป ไม่ต้องติดตั้ง package เพิ่ม

```bash
DASHBOARD_PASSWORD=ตั้งรหัสผ่าน npm start
# เปิด http://localhost:3000 (แบบฟอร์ม) และ http://localhost:3000/dashboard
```

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตของเว็บ |
| `DASHBOARD_PASSWORD` | (ว่าง) | รหัสผ่านสำหรับเข้า Dashboard (**ควรตั้ง** เพราะมีชื่อและเบอร์โทรพนักงาน) |
| `DASHBOARD_USER` | `admin` | ชื่อผู้ใช้สำหรับเข้า Dashboard |
| `DATA_DIR` | `./data` | โฟลเดอร์เก็บไฟล์ข้อมูล `responses.json` |

## ความสามารถ

**แบบฟอร์ม**
- ครบทุกหัวข้อ: ชื่อ-นามสกุล, ลักษณะที่อยู่อาศัย (ถามชั้นเฉพาะหอพัก/คอนโด/แฟลต), บริเวณที่พัก, ใช้นอนได้หรือไม่, อาหารพอกี่วัน, ระดับน้ำ, การเดินทางมาทำงาน, เบอร์โทร, ระดับความต้องการความช่วยเหลือ และช่องหมายเหตุ (ไม่บังคับ)
- ตรวจสอบข้อมูลทั้งฝั่งหน้าเว็บและเซิร์ฟเวอร์
- ถ้ากรอกซ้ำด้วยเบอร์โทรเดิม ระบบจะ **อัปเดต** ข้อมูลเดิมเป็นสถานการณ์ล่าสุด (ไม่สร้างรายการซ้ำ)

**Dashboard**
- อัปเดตทันทีเมื่อมีคนส่งข้อมูล (Server-Sent Events) ไม่ต้องกด refresh
- ตัวเลขสรุป: จำนวนผู้ตอบ, ต้องการที่พักแต่ยังไม่มีที่ไป (เร่งด่วน), ต้องการออกจากที่พัก, ที่พักใช้นอนไม่ได้, อาหารเหลือ ≤ 2 วัน, มาทำงานไม่ได้
- กราฟแท่งแยกตามทุกหัวข้อ คลิกที่แถบเพื่อกรองได้
- ตัวกรองแบบ dropdown ทุกหัวข้อ + ช่องค้นหาชื่อ/บริเวณที่พัก/เบอร์โทร
- ตารางรายชื่อ เรียงลำดับได้ทุกคอลัมน์ กดเบอร์โทรเพื่อโทรออกได้ และลบรายการได้
- ดาวน์โหลดข้อมูลทั้งหมดเป็น CSV (เปิดใน Excel ภาษาไทยได้)

## การแก้ไขตัวเลือก

ตัวเลือกของแต่ละคำถามอยู่ใน `public/options.js` ที่เดียว ใช้ร่วมกันทั้งแบบฟอร์ม Dashboard และการตรวจสอบฝั่งเซิร์ฟเวอร์

## หมายเหตุการ deploy

ข้อมูลเก็บเป็นไฟล์ JSON บนเครื่องเซิร์ฟเวอร์ จึงต้อง deploy บนเครื่อง/บริการที่มี disk ถาวร (เช่น VM, Render/Railway พร้อม persistent volume) และรันเพียง 1 instance
